БИЗНЕС БЕЗ ХАОСА — полный исходный комплект v3.6

ЧТО ВНУТРИ
public/index.html — клиентская диагностика на основе дерева v2.7, локальное сохранение, отчёт HTML и JSON.
src/index.js — единый сервер: сохранение в D1, выдача записей и выгрузка.
/admin — закрытая страница организатора (вход по секретному ключу).
schema.sql — создание таблицы в D1.
wrangler.toml — конфигурация Cloudflare Worker + Assets + D1.

ВАЖНО: это исходный комплект, НЕ ZIP для простого перетаскивания в Cloudflare Pages.
Для установки требуется создать D1, заменить REPLACE_WITH_YOUR_D1_DATABASE_ID на реальный ID,
развернуть проект через Wrangler (или GitHub + Cloudflare Workers Builds), выполнить schema.sql
в базе и создать секрет ADMIN_TOKEN (через Cloudflare Worker Settings → Variables and Secrets).
Секретный ключ не вставлять в чат и не размещать в исходном коде.

Участник: / — проходит диагностику, скачивает свой отчёт и JSON; кнопка серверного сохранения
передаёт ответы на сервер. Организатор: /admin — вводит ADMIN_TOKEN и скачивает записи.

ОГРАНИЧЕНИЯ: нужно проверить сквозной путь после публикации; отчёт предварительный;
при выгрузке «все» ограничение 1000 записей, просмотр — 50 записей на страницу.
Не собирайте идентифицирующие персональные данные клиентов до юридической проверки
согласия, политики обработки данных и требований к локализации хранения.
